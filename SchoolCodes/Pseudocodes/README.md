# Pseudocode

Algorithms written in exam-style pseudocode, the planning step before
writing them in Java. Files marked "Annotated" explain each line.

They cover a calculator, a day finder, factorials, prime and factor checks,
a palindrome checker, the largest of three numbers, multiplication tables,
odd and even counting, and temperature conversion.

The Java versions of most of these are in [`../Java`](../Java).
