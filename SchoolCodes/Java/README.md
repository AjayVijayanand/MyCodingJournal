# School Java programs

Java written for my pre-university computer science classes. This is where I
first implemented the standard data structures and algorithms by hand.

| Topic | Files |
| --- | --- |
| Searching | `LinearSearchInt`, `LinearSearchChar`, `BinarySearchRecursiveInt`, `BinarySearchRecursiveChar` |
| Sorting | `BubbleSortInt`, `BubbleSortString`, `SelectionSort` |
| Stacks and queues | `Stacks` with `Stack_Operations`, `Queue` with `Queue_Operation`, each built on a plain array |
| Recursion | `Factorial_Recursive`, `Fibonnachi_Recursive` |
| Arrays | adding, deleting and reversing elements, sums, duplicates, odd and even splits, rearranging |
| 2D arrays | `Matrix_Operations`, `Diagonal_Sum` |
| Objects and classes | `Travel`, `Figure` |
| Loops and conditions | number and star patterns (`Pattern1` to `Pattern8`), primes, twin primes, factorials, progressions, a calculator |

`GeneticAlgorithm.java` is not my code. It is a published example by another
author, credited at the top of the file, that I kept as a reference while
studying genetic algorithms for a case study.

All file names above end in .java.
