# Cambridge IGCSE pre-release tasks

My solutions to the pre-release programming tasks for Cambridge IGCSE
Computer Science (syllabus 0478), written between 2018 and 2020 while I was
preparing for the exam. File names follow the paper codes, so `s16_pm_21` is
the summer 2016 paper 21.

These are the earliest programs in this repository. They show where I
started: input validation, lists and totals, written without functions.

| File | Task |
| --- | --- |
| `0478_s15_pm_21.py`, `0478_s15_pm_23.py` | Record midday and midnight temperatures for 30 days and report averages and extremes |
| `0478_s15_pm_22.py` | Track students' weights at the start and end of term |
| `0478_w15_pm_21.py`, `0478_w15_pm_22.py` | Monitor a baby's temperature at fixed intervals and flag abnormal readings |
| `0478_w15_pm_23.py` | Monitor an apartment's temperature and decide when to switch on heating or cooling |
| `0478_s16_pm_21.py` | Accept or reject parcels by size and weight and total the price |
| `0478_s16_qp_22.py` | Check sacks of cement, gravel and sand against weight limits |
| `0478_m18_pm_22.py` | Allocate students to their chosen subjects |
| `0478_S20_QP_22.py` | A car park payment system: price by day and arrival time, discounts for frequent parkers, and a daily total |
| `CS0478_S20_QP_21.java` | A phone shop ordering task, written in Java |
| `0478_S21_QP_22` | A train seat booking task, written in pseudocode |

Built with Python, plus one Java file and one pseudocode file.
