# Gallery photos

Every image in this folder appears in the Gallery section of the portfolio
site. To add photos, put them here and push. To remove one, delete its file.

- **Formats:** `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif` or `.avif`.
- **Order:** alphabetical by file name, so prefix names with `01-`, `02-` and
  so on to choose the order.
- **Descriptions:** the file name becomes the photo's description for screen
  readers, so `marina-bay-sunset.jpg` reads as "marina bay sunset".
- **Size:** keep each photo under about 1 MB (around 2000 pixels on the long
  side) so the page loads quickly. Camera originals are far larger than that,
  so shrink them first. The full-size originals of the current photos are
  kept in `gallery-originals/` next to this folder, which is not uploaded.

The layout adjusts itself to however many photos there are and whatever
shape they are.
