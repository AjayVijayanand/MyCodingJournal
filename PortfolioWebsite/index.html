Projects

  • Spotify song popularity classifier

    Group project, NTU IE0005 Introduction to Data Science and AI

    Can a song's audio features predict how popular it will be? I contributed to an ensemble machine learning classifier that tries to answer that, trained on the most-streamed Spotify songs of 2023.

    • Used about 950 songs and six audio features: danceability, valence, energy, acousticness, instrumentalness and speechiness.
    • Split songs into low, medium and high popularity by stream count, then explored the data with a correlation heatmap, pair plots and per-feature distributions.
    • Trained K-nearest neighbours on standardised features, a random forest tuned with five-fold GridSearchCV, and a soft-voting ensemble of the two.
    • Checked which features each model relied on using permutation importance.
    • The best models reached about 43% accuracy against 33% for guessing. The finding was that audio features alone say little about streams, which probably depend more on things outside the data, such as the artist's existing audience.

    Python, scikit-learn, pandas, seaborn, Jupyter

  • Automated data-quality and Excel reporting tool

    For a family member's small business, built and shipped in a day

    Checking a batch of Excel workbooks by hand means opening each one and reading every row. I wrote a Python tool that does the whole batch in one run and marks the problems inside the workbooks themselves.

    • Flags rows with missing fields and text that is over its length limit, filling the cell red so problems are visible as soon as the file is opened.
    • Writes live Excel formulas that classify each entry as simple, moderate or complex, so the sheet keeps updating as people edit it.
    • Works out where the real data ends, ignoring trailing blank rows that would otherwise trigger false warnings.
    • Produces a summary workbook with the counts for every file in the batch.
    • Extracts embedded images from spreadsheets, with a companion script that does the same for PDFs.

    Python, openpyxl, PyMuPDF

  • Automatic volume-controlled audio amplifier

    NTU EE2073, AY2025/26

    An audio amplifier that keeps its output level steady whether the input is quiet or loud. It is a closed-loop system on an STM32 microcontroller, programmed in Python.

    • Built three subsystems and integrated them: a voltage-controlled amplifier, a power amplifier and a VU meter.
    • Maintained a stable output across a wide range of input levels.
    • Validated a flat frequency response across the audible range.
    • Characterised the voltage-controlled amplifier's gain across its full control-voltage range.
    • Debugged clipping and grounding noise that appeared when the subsystems were joined.

    STM32, Python, Jupyter, closed-loop feedback

  • Three-stage analog stethoscope signal chain

    NTU EE2102, AY2025/26

    An electronic stethoscope front end that takes faint body sounds from a microphone and makes them loud enough to hear through an earpiece, designed in simulation and then measured on an oscilloscope.

    • Stage one, microphone preamplifier: an inverting op-amp circuit designed for a target closed-loop voltage gain in the audible band, with a feedback capacitor to suppress high-frequency noise.
    • Stage two, log-scale VU meter: a row of LEDs that light at progressively higher peak voltages using diode threshold logic, showing the signal level at a glance.
    • Stage three, power amplifier: a common-collector emitter-follower buffer that supplies the current a low-impedance earpiece needs, which the op-amp alone cannot deliver.

    Op-amp and BJT circuits, LTspice, oscilloscope measurement
