Projects

  • Spotify song popularity classifier

    Can a song's audio features predict how many streams it gets? A group project that trains K-nearest neighbours, a random forest and a voting ensemble on 2023's most-streamed songs, then uses permutation importance to see which features matter.

    Python, scikit-learn, pandas, seaborn

  • Excel data automation tool

    Scripts that check a folder of Excel workbooks in one run: they flag incomplete rows and over-long text in red, write live formulas, pull out embedded images and produce a summary sheet.

    Python, openpyxl

  • TermComm

    A chat room and a small blog that run in the terminal and store everything in MongoDB, with accounts, hashed passwords and separate admin and reader roles.

    Python, pymongo, MongoDB Atlas

  • JavaJam Coffee House (in progress)

    A multi-page coffee house site that I first built in plain HTML, CSS and PHP, and am now rebuilding in React as an optional extra: reusable components, controlled form inputs and per-field validation.

    React, Vite, JavaScript, CSS

  • Automatic volume-controlled audio amplifier

    A closed-loop audio amplifier built around an STM32, with a voltage-controlled amplifier, power stage and VU meter. Measured for flat frequency response and steady output across a wide range of input levels.

    STM32, Python, Jupyter

  • Three-stage stethoscope signal chain

    A discrete analog chain for a stethoscope microphone: op-amp preamplifier, diode-based VU meter and transistor output buffer, simulated first and then checked on an oscilloscope.

    LTspice, op-amp and BJT circuits

The rest of my code, including Advent of Code solutions and coursework in C and Java, is in MyCodingJournal.
