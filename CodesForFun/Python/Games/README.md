# Terminal games

Small games that run in the terminal. I wrote these to practise loops, input
validation, randomness and, in the later ones, classes.

| File | Game |
| --- | --- |
| `PocketCricketSimulator.py` | The largest one: a dice cricket game with separate batting and bowling dice, conservative and aggressive shots, and a screen that clears between turns |
| `HandCricketSimulator.py` | Hand cricket against the computer, with a toss and two innings |
| `BookCricketSimulator.py` | Book cricket with ball-by-ball commentary |
| `SnakesAndLadders.py` | Snakes and ladders, using a `Player` class to track each position |
| `WordGuesser.py` | Guess a hidden word letter by letter, drawn from the word list in `hrt.txt` |
| `RockPaperScissors.py` | Rock, paper, scissors with a running score |

Built with Python's standard library only.
