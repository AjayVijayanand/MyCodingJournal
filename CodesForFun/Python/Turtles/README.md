# Turtle graphics

Patterns drawn with Python's `turtle` module. Several are kolams, the
dot-and-line designs traditionally drawn at the entrance of Tamil homes.

| File | Draws |
| --- | --- |
| `Kolam + Dot.py` | A kolam built from two reusable functions for the loops and the dot grid |
| `Kolam + Dot 2.py` | A second kolam in white on black |
| `K3.py` | A diamond-shaped dot grid, placed one dot at a time |
| `RecursiveDesign.py` | A spiralling polygon whose sides shrink and fade with each step |
| `T.py` | A randomly coloured flower of arcs |
| `Turtle.py` | Nested triangles of dots, sized from user input |

Built with Python's standard library only.
