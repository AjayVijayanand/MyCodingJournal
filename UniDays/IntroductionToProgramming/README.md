# Introduction to Computational Thinking and Programming in C

C programs from my first-year programming course at NTU: two graded home
assignments plus the lab and tutorial exercises.

| What | Files |
| --- | --- |
| Home assignment 1 | `HW1_VijayAnandAjay.c`: circumference and area of a circle, and volume and surface area of a sphere, from a radius |
| Home assignment 2 | `HW2_VijayAnandAjay.c`: common factors of three three-digit numbers, one typed in, one random and one reversed |
| Physics and circuits | `projectile.c`, `particalgravity.c`, `series_circuit.c` |
| Maths | `quadratic.c`, `cubicfunc.c`, `approxE.c`, `sinc.c`, `minimum.c`, `triangles.c` |
| Everyday calculations | `BankInterest.c`, `ahlongpteltd.c` (compound interest), `tempconv.c`, `hrstomin.c` |
| Control flow | `CalculatorIF.c`, `CalculatorCASE.c`, `chk_case1.c` |
| Random numbers | `dice.c`, `rando.c`, `srando.c` |
| Variable scope | `scope3.c`, `scope4.c`, `scopenested.c`, `scopefileblk.c` |
| Tutorial questions | `question1.c` to `question4.c`, `question56.c`, `exercise3.c`, `exercie5.c` |

Files ending in "copy" are earlier drafts of the file with the same name.

Built with C.
