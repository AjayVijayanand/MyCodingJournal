# Practice notebooks

The course's practice notebooks, which I worked through alongside the
lectures. Most use a dataset of Pokemon statistics (`pokemonData.csv`).

| Notebook | Topic |
| --- | --- |
| `M1 DataAcquisition.ipynb` | Reading CSV, text, Excel, JSON and web tables into pandas, using the files in `data/` |
| `M2 BasicStatistics.ipynb` | Summary statistics and distribution plots |
| `M2 ExploratoryAnalysis.ipynb` | Exploring and cleaning the dataset |
| `M3 LinearRegression.ipynb` | Linear regression with a train and test split and goodness-of-fit measures |
| `M4 ClassificationTree.ipynb` | Decision trees and confusion matrices |
| `M5 ClusteringPatterns.ipynb` | K-means clustering and choosing the number of clusters |
| `M5 DetectingAnomalies.ipynb` | Anomaly detection with local outlier factor |
