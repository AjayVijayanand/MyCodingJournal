# Introduction to Data Science and Artificial Intelligence

Notebooks from NTU's introductory data science course, which runs from
loading data through to regression, classification and clustering.

| Folder or file | Contents |
| --- | --- |
| [`MiniProject_TopSongs/`](MiniProject_TopSongs) | The group mini-project: predicting song popularity from Spotify audio features |
| [`HousePrices/`](HousePrices) | Six weekly exercises on one housing dataset, one technique per week |
| [`Practice/`](Practice) | The course's practice notebooks, worked through module by module |
| `wikipediaOMT.ipynb` | Reads the 2016 Summer Olympics medal table straight from Wikipedia into pandas and ranks countries two different ways |
| `PythonFam_Problem.ipynb` | Warm-up problems for getting used to Python and Jupyter |
| `exercise0.py`, `exercise0.ipynb` | A file-handling exercise that checks a list of site visitors against a block list (`visitors.txt`, `blocklist.txt`) |

Built with Python, pandas, NumPy, seaborn, Matplotlib and scikit-learn.
