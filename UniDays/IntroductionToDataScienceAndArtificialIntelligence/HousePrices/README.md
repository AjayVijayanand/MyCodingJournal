# House prices exercises

Six weekly exercises on the Kaggle
[House Prices](https://www.kaggle.com/c/house-prices-advanced-regression-techniques)
dataset. Each week applies one new technique to the same data.

| Notebook | Exercise |
| --- | --- |
| `HousePricesWeek2.ipynb` | Data acquisition: loading and inspecting the dataset |
| `HousePricesWeek3.ipynb` | Basic statistics and distributions |
| `HousePricesWeek4.ipynb` | Exploratory analysis of numeric and categorical variables |
| `HousePricesWeek5.ipynb` | Linear regression, starting with sale price against living area |
| `HousePricesWeek6.ipynb` | Classification trees, judged with a confusion matrix |
| `HousePricesWeek7.ipynb` | K-means clustering and anomaly detection |
| `HousePricesMain.ipynb` | Scratch notebook for setting up the data |

`train.csv` is the dataset and `data_description.txt` explains its columns.

Built with Python, pandas, seaborn and scikit-learn.
