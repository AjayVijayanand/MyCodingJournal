# Advent of Code

My solutions to [Advent of Code](https://adventofcode.com/), a yearly set of
programming puzzles.

| File | Contents |
| --- | --- |
| `day1.py` | 2023, Day 1: find the first and last digit on each line, where digits can also be spelled out as words, and sum the results |
| `info.txt` | My puzzle input |

The tricky part of this puzzle is overlapping words such as "oneight", which
the solution handles with a lookup table and a regular expression.

Built with Python.
